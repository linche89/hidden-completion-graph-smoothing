# 局部状态估计第三阶段执行规范

## 1. 本阶段目标

本阶段只推进两件事：把候选数学结论收紧到可以逐行审查的定理与证明；把与这些定理直接对应的本地 CPU/GPU 实验跑通。集群、MPI 和多机扩展不列入近期交付，也不在论文草稿中提前声称。

论文主问题保持为：对有环 Gaussian/WLS 网络，在算法只能使用有限邻域模型和数据、并允许至多 \(\delta\) 比例输出节点失败时，何时能在误差 \(\varepsilon\) 内逼近中心估计，以及达到该误差需要多少通信、计算和内存。

## 2. 原创性判定规则

任何候选结果必须分别通过四道检查：

1. **公式正确性**：固定输入范数、模型类、信息归属、目标输出和失败量词，给出完整证明；
2. **边界正确性**：列出使结论失败的最小反例，以及每个附加假设不能删除的原因；
3. **文献包含关系**：逐条与已有定理比较假设、结论、范数和量词，不用关键词搜索结果代替数学比较；
4. **计算对应关系**：实验直接测量定理中的量，不以平均状态误差或运行时间替代最坏块行误差和节点分位数。

只有同时通过上述检查的部分才进入“可能的新定理”。Schur 补、Green 函数、随机游走基本矩阵、稀疏逆衰减和 Chebyshev 逼近均按标准工具处理；创新只能来自新的量词组合、更弱且必要的稳定性条件、匹配上下界或新的不可能性结论。

“截至当前没有检索到”只表示有发表潜力，不等于数学意义上的全球首创证明。最终原创性结论仍需经过投稿前的独立专家审读和针对定理表述的持续检索。

## 3. 数学工作包

### 3.1 通用 block-SPD 路线

需要收口的对象是：

- 固定模型、任意解码器的球外块行精确误差；
- 所有相同局部视图的远端扩展必须共用同一线性系数时的最坏误差；
- principal/零边界局部解与全局最佳球内截断之间的 Schur 精确分解；
- 对 \(1-\delta\) 节点分位数的双向界；
- 从 primitive right-hand side \(b\) 回到原始观测 \(z\) 时，\(G=H^*R^{-1}\) 的局部性和局部右逆条件。

该路线覆盖面广，但 Schur 恒等式本身是经典线性代数。若最终只能得到统一条件数下的指数衰减，应把它降为背景或基线，而不是主贡献。

### 3.2 Grounded Laplacian/M-matrix 路线

需要收口的对象是：

- 最优球内截断、局部零边界解和有限步迭代分别对应的随机游走占用量；
- 对节点测度的 \((1-\delta)\)-分位数条件；
- 出球概率与剩余寿命共同给出的双向局部证书；
- 任意远端扩展下的长悬挂路径反例；
- \(\ell_2\) 输入下两条独立随机游走交叉占用量与块系统中路径抵消的限制。

这条路线更容易给出图论和概率论解释，也更适合作为主定理候选。但 Green 函数的随机游走表示本身是经典的，必须把新意放在局部算法误差的精确区分、completion 的必要边界和多数节点量词上。

## 4. 可执行数学核验

`experiments/test_theory_identities.py` 当前核验：

- 随机 SPD 分块矩阵上的 Schur 因子分解；
- oracle 球外误差与局部 Dirichlet 误差的双向范数界；
- grounded Laplacian 中 oracle、Dirichlet 和 Neumann 三种误差的顺序；
- 出球概率与剩余寿命上界；
- 单锚点路径的球外行尾随悬挂长度增长；
- 一般矩阵区间单向量像的椭球构造，以及各向异性投影相对两个标量端点的严格 gap；
- Neumann/Richardson 行误差的节点谱测度恒等式、whitened WLS 中低谱权重由 \(\lambda^{-2}\) 变为 \(\lambda^{-1}\) 的恒等式，以及局部化/离域小特征模态对多数节点的不同影响。

这些测试只用于防止公式实现错误，不构成证明，也不用于判断原创性。后续每个反例和主要推论都应增加确定性回归测试。

## 5. 本地 CPU 实验

### 5.1 实例层次

1. 合成图：路径、环、网格、随机几何图、随机正则图、社区图、哑铃图和严格验证的局部不可区分成对实例；
2. PGLib DC-WLS：14、118、300、1,354、2,869、10,000 节点；
3. 条件允许后按需增加 30,000 和 78,484 节点实例；
4. SuiteSparse 只用于矩阵和图局部性压力测试，不替代状态估计模型。

### 5.2 实现约束

- 从因子生成到正规方程均直接使用 COO/CSR，不建立稠密 \(H\)、\(J\) 或 \(J^{-1}\)；
- 小规模中心参考使用稀疏直接法，大规模使用带显式残差检查的迭代法；
- 中心估计算子块行只对抽样根做转置求解；
- 测量依赖的状态变量与测量的初始持有者分别保存；
- 局部 principal block 与“删除跨边界测量后重新组装的矩阵”作为两个不同对象；
- 同一批半径、随机图和噪声实验使用预注册种子和机器可读配置。

### 5.3 必报指标

- 中心残差、局部状态误差和抽样块行误差；
- \(g_i(r)\)、\(d_i(r)\)、局部放大因子及其节点分位数；
- 达到指定 \((\varepsilon,\delta)\) 的最小半径；
- 构造、预处理、求解和统计各阶段时间；
- 稀疏非零元、进程峰值内存、每轮消息标量数和 bit-hop 代理；
- 根节点抽样的置信区间，并将图实例随机性与节点抽样误差分开。

## 6. 本地 GPU 实验

当前机器的 RTX 5080 和 CUDA 12.8 可以作为单机 GPU 路线。CuPy 的稳定版安装文档列出 Windows、Python 3.13 和 CUDA 12.x wheels，且其稀疏线性代数提供 SPD 共轭梯度接口[^1][^2]。实现放入项目隔离环境，不修改系统级 CUDA 或全局 Python。

GPU 第一阶段只测试适合其结构的任务：批量 CSR SpMV、Jacobi/Chebyshev/Neumann 迭代以及相同矩阵上的多右端项 CG。逐根 BFS、大小差异很大的局部稀疏分解和 CPU 上完成的 LU 预处理不写成 GPU 加速贡献。

CPU/GPU 比较必须满足：

- 同一矩阵、右端项、精度和停止准则；
- 至少一次预热，使用显式 GPU 同步计时；
- 分别报告主机到设备传输、设备计算和设备到主机传输；
- 同时报端到端时间和纯 kernel 时间；
- 报告残差、迭代次数和数值精度，不能只报速度比；
- 对小矩阵 GPU 较慢的结果如实保留，并寻找出现加速的规模阈值。

## 7. 本阶段验收门槛

数学线满足以下条件才进入论文正文：定理陈述无隐藏全局知识；证明完整；经典部分逐项归属；至少一个附加条件有匹配反例；独立文献审计没有找到更强的现成同型结论。

实验线满足以下条件才称为“大规模验证”：正式生成器全程稀疏；PGLib 转换可复现；小案例与中心参考一致；至少一个 10,000 节点实例跑通；不形成完整逆矩阵；CPU/GPU 使用相同误差标准。72 节点 smoke test 仍只称为正确性测试。

若 GPU 在可容纳规模上没有端到端收益，应如实结论为“不适合当前算法结构”，而不是继续堆叠优化。若候选数学结果最终只是经典条件数衰减的改写，则停止把它作为主定理，转向 completion 不可能性或更弱的剩余寿命/容量条件。
